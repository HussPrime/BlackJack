# ♠️ Blackjack 3D Web Game

Un jeu de **Blackjack interactif en 3D** développé en JavaScript avec une interface HUD moderne et responsive.  
Le projet inclut un système de mise dynamique, une interface utilisateur élégante et un panneau de règles intégré.

---

## 🎮 Fonctionnalités

- 🃏 Logique complète du Blackjack  
- 🎮 Actions pricipaux (Hit, Stand)
- 🎲 Système de mise avec slider interactif  
- 🏆 Affichage dynamique des scores  
- ✨ Interface HUD moderne (glassmorphism)  
- 📱 Design responsive (mobile / tablette / desktop)  
- 📖 Overlay des règles accessible à tout moment

## 🎯 Règles du jeu

Le Blackjack est un jeu de cartes où le but est d’atteindre **21 points** ou de s’en approcher sans dépasser.

- Les cartes numériques valent leur valeur  
- Les figures valent 10  
- L’As vaut 1 ou 11  
- Le joueur peut :  
  - **Hit** → tirer une carte  
  - **Stand** → rester  
- Si le joueur dépasse 21 → il perd  
- Si le croupier dépasse 21 → le joueur gagne  
- Le plus proche de 21 gagne la manche
